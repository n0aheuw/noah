# Hi there, welcome to my Portfolio Website Repo 👋

This is my repository for my new portfolio website built with React, Tailwind CSS, and JavaScript using Vite as the build tool.  
It was created following a basic portfolio design tutorial from [this YouTube video](https://www.youtube.com/watch?v=LGdPMf-SgBA&t=904s).

The old version of the website is now located in the `/archive` folder.

### Features
- Responsive layout built with Tailwind CSS  
- Interactive UI powered by React  
- Fast build and hot module replacement with Vite  
- Clean and modern portfolio design  
- Easy to customize and extend
